# Changing an Order or Shipping Address

## Changing items in an order
Orders cannot be edited after they are placed. To change items, cancel the order while it is still in PROCESSING and place a new one.

## Changing the delivery address before shipping
While an order is in PROCESSING, support can update the delivery address once, provided the new address is in the same country. Changes to a different country require cancelling and placing a new order.

## Changing the address after shipping
Once an order is SHIPPED we cannot change the address ourselves. You can use the carrier's own redirect service from the tracking page; some carriers charge for this.

## Upgrading shipping speed
Standard shipping can be upgraded to express while the order is still in PROCESSING. The difference in shipping cost is charged to the original payment method.

## Wrong address entered
If an order was delivered to an address you entered by mistake, we cannot reship it for free. Contact the carrier first; we can help if the parcel is returned to us.
