# Promo Codes and Discounts

## Using a promo code
Enter the code at checkout before paying. Codes cannot be added to an order after it has been placed, and support cannot apply them retroactively.

## Stacking rules
Only one promo code can be used per order. Promo codes can be combined with gift cards and rewards points, but not with clearance prices or bundle discounts.

## Why a code is not working
The most common reasons are that the code has expired, the basket is below the minimum spend, the items are excluded (gift cards and clearance items usually are), or the code was single-use and has already been redeemed on your account.

## Refunds on discounted orders
If you return part of an order that used a promo code, the refund is the price you actually paid for that item after the discount was spread across the order. If the return brings the order below the code's minimum spend, the discount on the remaining items is not clawed back.

## Student and military discounts
Verified students and military personnel get 10% off full-priced items. Verification is done once a year through our partner and the discount is applied automatically at checkout.
