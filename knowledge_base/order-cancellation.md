# Order Cancellation Rules

## Which orders can be cancelled
Orders can only be cancelled while in PROCESSING status. Once an order has SHIPPED or DELIVERED, direct cancellation is disabled and the customer must initiate a return.

## How to cancel
Ask the support assistant to cancel the order, quoting the order number. The assistant first checks whether the order is still in PROCESSING; if it is, the cancellation is applied immediately and confirmed in the conversation.

## Refund after cancelling
Cancelling an order releases the payment hold. If the card was already charged, the full amount is refunded to the original payment method within 5-7 business days.

## Cancelling part of an order
Individual items cannot be removed from an order that is in PROCESSING. You can cancel the whole order and place a new one, or keep the order and return the unwanted item after delivery.

## Orders that were already cancelled
A cancelled order cannot be cancelled again or reopened. Place a new order if you still want the items.
